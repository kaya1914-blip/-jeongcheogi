# 정현준 자격증 학습 (통합 앱)

정보처리기사 필기와 네트워크관리사 2급 필기를 **한 앱**에서 공부합니다.
앱을 열면 나오는 포털에서 자격증을 고르고, 각 자격증의 **교재**와 **모의고사**로 들어갑니다.
푼 기록은 자격증별로 따로 저장되어 섞이지 않습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 포털 — 자격증 선택 화면 (앱 시작점) |
| `jeongcheogi.html` · `jeongcheogi-exam.html` | 정보처리기사 교재 · 모의고사 |
| `network.html` · `network-exam.html` | 네트워크관리사 2급 교재 · 모의고사 |
| `manifest.webmanifest` · `sw.js` · `icons/` | 앱 설치·오프라인용 |

## 깃허브 · 설치 — 기존 정처기 저장소에 그대로 넣는다

새 저장소를 만들 필요 없이 **지금 쓰는 정처기 저장소**에 올리면 됩니다.
통합 포털 안에 정처기가 이미 들어 있어, 루트가 포털로 바뀌면 **같은 링크가 통합 앱**이 됩니다.

- 저장소: `kaya1914-blip/-jeongcheogi`
- 올리는 곳: https://github.com/kaya1914-blip/-jeongcheogi/upload/main
- 주소(Pages): https://kaya1914-blip.github.io/-jeongcheogi/

**올리는 법**
1. `2_깃허브_업로드용` 폴더의 파일을 위 upload 페이지에 통째로 끌어다 놓고 커밋합니다.
   - `index.html`·`manifest.webmanifest`·`sw.js`·`icons/` 는 덮어써집니다 → 루트가 포털이 됩니다.
   - `jeongcheogi.html`·`jeongcheogi-exam.html`·`network.html`·`network-exam.html` 이 새로 추가됩니다.
2. 예전 정처기 단독 파일 **`textbook.html`·`exam.html`** 은 이제 안 쓰입니다.
   깔끔하게 하려면 저장소에서 두 파일을 지워도 되고, 그냥 둬도 아무 문제 없습니다(아무 데서도 안 부름).
3. 이미 정처기 앱을 폰에 설치해 뒀다면, 다음에 열 때 **학사모 아이콘의 통합 앱으로 바뀝니다**.
   푼 기록은 그대로 이어집니다(정처기 키·네트워크 키를 따로 저장하므로).

**폰 설치**: 위 주소를 폰 브라우저로 열고 — 아이폰은 사파리 공유(⬆️)→「홈 화면에 추가」,
안드로이드는 크롬 ⋮→「홈 화면에 추가」. 주소창 없이 전체 화면, 인터넷이 없어도 열립니다.

## 갱신 방법

- 정처기·네트워크 교재/모의고사를 각 프로젝트에서 새로 만든 뒤 **`python tools/sync.py`** 를 돌리면
  최신본이 통합 앱으로 따라오고 `2_깃허브_업로드용` 폴더가 새로 채워집니다. 그 폴더만 다시 올리면 됩니다.
- 포털 자체의 판을 올리려면 **`python tools/set_version.py`** 를 씁니다.
- **깃허브 올리기는 이제 자동**: `python tools/deploy.py` 또는 폴더의 **「깃허브에_올리기.bat」 더블클릭** — 복사·커밋·푸시까지 한 번에. 처음 1번만 브라우저 로그인(kaya1914-blip)이 뜨고, 그 뒤로는 로그인 없이 올라갑니다.
