1부코드 결과 쓰기 — 당락을 가르는 구간

실제 실기에서 프로그래밍 문항은 「다음 코드의 출력 결과를 쓰시오」 형태입니다. 변수 값을 표로 추적하며 읽는 습관을 들이세요.

C 언어 (7문)

1다음 C 코드의 출력 결과를 쓰시오. 배열·포인터
int a[] = {10, 20, 30, 40, 50};
int *p = a + 1;
printf("%d", *(p + 2) + a[0]);
정답

정답 50

정답 근거p는 a[1]을 가리키므로 *(p+2)는 a[3] = 40입니다. 여기에 a[0] = 10을 더해 50.

함정p가 a[0]이 아니라 a+1에서 시작한다는 것을 놓치면 30+10=40으로 틀립니다.

강사 한마디포인터 문제는 무조건 「지금 p가 몇 번 방을 가리키나」부터 여백에 적으세요. 시작 위치만 정확하면 나머지는 덧셈입니다.

2다음 C 코드의 출력 결과를 쓰시오. 재귀
int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}
int main() { printf("%d", f(4)); }
정답

정답 24

정답 근거f(4)=4×f(3)=4×3×f(2)=4×3×2×f(1)=4×3×2×1 = 24 (팩토리얼).

함정종료 조건이 n<=1에서 1을 반환한다는 것까지 확인해야 합니다. 0을 반환하면 전체가 0이 됩니다.

강사 한마디재귀는 아래로 내려가지 말고 f(1)부터 거꾸로 올라오며 계산하세요 — 1→2→6→24. 실수가 확 줄어듭니다.

3다음 C 코드의 출력 결과를 쓰시오. 비트 연산
int a = 13, b = 6;
printf("%d %d %d", a & b, a | b, a ^ b);
정답

정답 4 15 11

정답 근거13=1101₂, 6=0110₂. AND=0100₂=4, OR=1111₂=15, XOR=1011₂=11.

함정&&(논리)와 &(비트)를 혼동하면 안 됩니다. 논리 연산이면 1 1 0이 나옵니다.

강사 한마디비트 문제는 2진수를 위아래로 적고 세로로 비교하는 게 유일한 정공법입니다. 암산하면 꼭 한 자리 틀립니다.

4다음 C 코드의 출력 결과를 쓰시오. 반복문

for (i = 1; i <= 12; i++)

정답 6

정답 근거12의 약수는 1, 2, 3, 4, 6, 12 — 모두 6개입니다.

함정i가 1부터 12까지 포함(<=)이라는 점. <로 잘못 보면 12가 빠져 5가 됩니다.

강사 한마디반복 범위의 등호 유무가 실기 단골 함정입니다. for문을 보면 끝값이 포함인지 아닌지부터 동그라미 치세요.

int i, n = 0;
for (i = 0; s[i] != '\0'; i++)

정답 2

강사 한마디문자열 순회의 종료 조건이 '\0'(널 문자)라는 것 자체가 단답으로도 출제됩니다. 문자열 끝 = 널 문자, 세트로 기억하세요.

6다음 C 코드의 출력 결과를 쓰시오. static 변수
void f() {
    static int c = 0;
    c++;
    printf("%d", c);
}
int main() { f(); f(); f(); }
정답

정답 123

정답 근거static 지역 변수는 한 번만 초기화되고 호출이 끝나도 값이 유지됩니다. 1, 2, 3이 이어 붙어 123.

함정static이 없으면 매번 0에서 시작해 111이 출력됩니다. static 유무가 이 문제의 전부입니다.

강사 한마디「static = 살아남는 변수」. 코드에서 static이 보이면 출제 의도는 무조건 값의 누적입니다.

7다음 C 코드의 출력 결과를 쓰시오. 포인터·함수
void sw(int *x, int *y) {
    int t = *x; *x = *y; *y = t;
}
int main() {
    int a = 3, b = 7;
    sw(&a, &b);
    printf("%d %d", a, b);
}
정답

정답 7 3

정답 근거주소(&)를 넘겼으므로 함수 안의 교환이 원본 a, b에 반영됩니다(Call by Reference 효과).

함정포인터 없이 값만 넘기는 판이면 원본이 안 바뀌어 3 7 그대로입니다. &가 있는지가 판별 기준입니다.

강사 한마디swap 문제는 매년 옷만 갈아입고 나옵니다. 「&로 넘기면 바뀐다, 값으로 넘기면 안 바뀐다」 — 이 한 줄이면 두 유형 다 잡습니다.

Java (6문)

8다음 Java 코드의 출력 결과를 쓰시오. 오버라이딩
class A { void show() { System.out.print("A"); } }
class B extends A { void show() { System.out.print("B"); } }
public class Main {
    public static void main(String[] args) {
        A obj = new B();
        obj.show();
    }
}
정답

정답 B

정답 근거참조 타입은 A지만 실제 객체는 B입니다. 오버라이딩된 메서드는 실행 시점의 실제 객체 기준으로 호출됩니다(동적 바인딩).

함정「A obj = 이니까 A」라고 읽으면 걸립니다. new 뒤를 보세요.

강사 한마디실기 Java의 절반이 이 구조입니다. 왼쪽(타입)은 껍데기, new 오른쪽이 진짜 — 이 문장만 기억하세요.

9다음 Java 코드의 출력 결과를 쓰시오. static 필드
class Cnt {
    static int n = 0;
    Cnt() { n++; }
}
public class Main {
    public static void main(String[] args) {
        new Cnt(); new Cnt(); new Cnt();
        System.out.print(Cnt.n);
    }
}
정답

정답 3

정답 근거static 필드는 클래스에 하나라 모든 객체가 공유합니다. 생성자가 3번 실행되어 n=3.

함정static이 없으면 객체마다 따로 n을 가져 1이 됩니다.

강사 한마디C의 static(살아남기)과 Java의 static(공유하기)을 짝으로 정리해 두세요. 실기는 이 둘을 같은 회차에 나란히 내곤 합니다.

10다음 Java 코드의 출력 결과를 쓰시오. 배열·반복
int[] a = {1, 2, 3, 4, 5};
int s = 0;
for (int i = 0; i < a.length; i += 2)
    s += a[i];
System.out.print(s);
정답

정답 9

정답 근거i가 0, 2, 4로 움직여 a[0]+a[2]+a[4] = 1+3+5 = 9.

함정「짝수 번째 값」이 아니라 짝수 인덱스의 값입니다. 2+4=6으로 답하면 인덱스와 값을 혼동한 것입니다.

강사 한마디배열 문제는 표를 그리세요 — 위 칸에 인덱스 0~4, 아래 칸에 값. 30초 투자로 실수가 사라집니다.

12다음 Java 코드의 출력 결과를 쓰시오. 생성자·상속
class P { P() { System.out.print("P"); } }
class C extends P { C() { System.out.print("C"); } }
public class Main {
    public static void main(String[] args) { new C(); }

정답

정답 PC

정답 근거자식 생성자가 실행되기 전에 부모 생성자가 먼저 호출됩니다(super() 자동 삽입). P → C 순.

함정new C()만 보고 "C"라고 쓰기 쉽습니다. 상속 관계면 부모부터입니다.

강사 한마디「집을 지으려면 기초(부모)부터」 — 생성은 부모→자식, 소멸은 자식→부모. 순서 문제는 이 비유 하나로 끝납니다.

13다음 Java 코드의 출력 결과를 쓰시오. 증감 연산자

정답

정답 6 9 14

정답 근거a++는 현재값 5를 쓰고 나서 6으로 증가. --b는 먼저 9로 줄인 뒤 사용. c = 5 + 9 = 14.

함정++/--의 앞뒤 위치가 전부입니다. 둘 다 후위로 읽으면 c=15로 틀립니다.

강사 한마디기호가 앞이면 먼저 바꾸고, 뒤면 나중에 바꿉니다. 저는 식 위에 「지금 쓰는 값」을 연필로 적으며 풉니다 — a++⑤, --b⑨처럼.

3부용어 단답 — 설명을 읽고 용어 쓰기

실기 용어 문제는 「다음 설명에 해당하는 용어를 쓰시오」 형태입니다. 영문 약어는 철자까지 정확히. 답을 소리 내어 말해 보고 정답을 여세요.

보안 (12)

1. 입력값 검증이 없는 웹 입력란에 악의적 질의문을 넣어 DB를 조작하는 공격

SQL 인젝션(SQL Injection) — 방어: 입력값 검증, Prepared Statement.

2. 게시판에 악성 스크립트를 심어 열람자의 브라우저에서 실행되게 하는 공격

XSS(크로스 사이트 스크립팅) — 쿠키·세션 탈취. CSRF(요청 위조)와 구분.

3. 로그인된 사용자의 권한으로, 본인 의도와 무관한 요청을 서버에 보내게 만드는 공격

CSRF(크로스 사이트 요청 위조) — 방어: 재인증, CSRF 토큰.

4. 다수의 좀비 PC로 동시에 대량 트래픽을 보내 서비스를 마비시키는 공격

DDoS(분산 서비스 거부 공격) — 봇넷이 공격 기반.

5. 파일을 암호화한 뒤 복호화 대가로 금전을 요구하는 악성코드

랜섬웨어(Ransomware) — 최선의 대비는 오프라인 백업.

6. 특정 조직을 노려 장기간 은밀하고 지속적으로 수행하는 지능형 표적 공격

APT(지능형 지속 위협) — Advanced Persistent Threat.

7. 네트워크의 패킷을 몰래 엿듣는 수동적 공격

스니핑(Sniffing) — 위조·변조하면 스푸핑(능동적).

8. 기술이 아닌 사람의 심리·신뢰를 이용해 정보를 빼내는 공격 기법의 통칭

사회공학(Social Engineering) — 피싱·스미싱이 대표.

9. 침입 징후를 탐지해 경보하지만 직접 차단하지는 않는 보안 시스템

IDS(침입 탐지 시스템) — 차단까지 하면 IPS.

10. 공중망 위에 암호화된 터널을 만들어 사설망처럼 안전하게 연결하는 기술

VPN(가상사설망) — VLAN(스위치 논리 분할)과 혼동 금지.

11. 보안 패치가 나오기 전의 취약점을 노리는 공격

제로데이(Zero-day) 공격 — 패치 이전이라 방어 수단이 없음.

12. 비밀번호 해시에 임의의 값을 덧붙여 무차별 대입·레인보 테이블을 어렵게 하는 기법

솔트(Salt) — 같은 비밀번호라도 해시가 달라짐.

암호 · 인증 (6)

13. 공개키·개인키 쌍을 쓰며 큰 수의 소인수분해가 어렵다는 점에 기반한 암호 알고리즘

RSA — 대표 비대칭키. ECC도 비대칭.

14. 미국 표준의 대칭키 블록 암호로, DES를 대체한 알고리즘

AES — 국산 대칭키는 SEED·ARIA.

15. 임의 길이 입력을 고정 길이로 바꾸며 역산이 불가능한 일방향 함수

해시 함수 — SHA 계열. 무결성 검증·비밀번호 저장.

전자서명(Digital Signature) — 기밀성은 제공하지 않음.

17. 한 번 쓰고 버리는 일회용 비밀번호

OTP(One-Time Password) — 재사용 공격 차단.

18. 정보보안 3대 요소를 순서대로 쓰시오

기밀성 · 무결성 · 가용성 — C·I·A.

ARP — 반대 방향(MAC→IP)은 RARP.
