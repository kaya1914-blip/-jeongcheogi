# 정처기 필기 합격 교재 📘

비전공자가 **정보처리기사 필기(평균 60점)** 를 넘기기 위해 만든 개인 학습 자료입니다.
저녁에 정독하고 아침에 5분 복습하는 리듬에 맞춰 짰습니다.

👉 **[바로 보기](https://kaya1914-blip.github.io/-jeongcheogi/)**

---

## 무엇이 들어 있나

| 파일 | 내용 |
|---|---|
| `index.html` | 시작 페이지 (교재·모의고사 입구, 설치 안내) |
| `textbook.html` | **필기 교재** — 5과목 본문 + 아침 복습 카드 + 문제은행 110문항 |
| `exam.html` | **실전 모의고사 100문항** + 약점 집중 드릴 6세트 |

### 교재
- 5과목 전체를 **원리부터** 설명 (비전공자 기준)
- 단원마다 3겹 — 본문(저녁 정독) · **아침 5분 복습 카드** · 기출 유형 체크
- 문제은행 **110문항**, 3개월 학습 로드맵, 합격 후기·무료 기출 사이트 모음

### 모의고사 앱
- **실전 모드** 150분 타이머 → 제출하면 과목별 점수·과락·합격 여부 자동 채점
- **학습 모드** 답을 고르면 즉시 해설
- **약점 드릴** 시험에서 서로 바꿔 내는 짝만 모은 6세트 (한 세트 5문항)
- 푼 내용 **자동 저장** → 이어풀기, 지난 응시 기록
- 폰 **홈화면 설치** · 오프라인 지원

### 해설 방식
문항마다 세 겹으로 답니다.

> **정답 근거** — 왜 그것이 답인지
> **함정** — 어느 오답이 왜 매력적인지
> **강사 한마디** — 실전에서 어떻게 판단할지

## 고치는 법

내용은 전부 HTML 한 파일씩입니다. 특별한 도구 없이 열어서 고치면 됩니다.

**가장 쉬운 방법 — 웹에서 끌어다 놓기**

1. 내 컴퓨터에서 `textbook.html` 이나 `exam.html` 을 고칩니다.
2. 깃허브 저장소 페이지에서 **Add file → Upload files**
3. 고친 파일을 끌어다 놓고 맨 아래 **Commit changes**

같은 이름으로 올리면 덮어써집니다. 몇 분 뒤 사이트에 반영됩니다.

**깃을 쓰신다면**

```bash
git clone https://github.com/kaya1914-blip/-jeongcheogi.git
# textbook.html 또는 exam.html 을 편집
git add -A && git commit -m "내용 수정" && git push
```

**문제를 추가하려면** `exam.html` 안의 `var EXAM`(모의고사) 또는 `var DRILL`(약점 드릴) 배열에 항목을 넣습니다.

```js
{t:"분류", q:"문제 내용",
 o:["보기1","보기2","보기3","보기4"], a:2,      // a = 정답 번호(0부터)
 why:"정답 근거", trap:"함정", coach:"강사 한마디"}
```

### 판(버전) 올리기 — 고쳤으면 꼭 하세요

```bash
python tools/set_version.py        # 판을 1 올린다 (v2 → v3)
python tools/set_version.py --show # 지금 판 보기
```

모든 파일(`index.html` · `textbook.html` · `exam.html` · `sw.js`)의 판을 한 번에 맞춰 줍니다.

**왜 필요한가** — 판을 올려야 ⑴ 이미 설치한 폰이 새 파일을 받아오고,
⑵ 앱을 열었을 때 **「새 판으로 갱신됐습니다 v2 → v3」** 알림이 떠서 반영 여부를 바로 알 수 있습니다.
화면 위쪽에는 항상 `v3 · 2026-08-20` 처럼 판과 날짜가 보입니다.

### 인쇄용 PDF 만들기

```bash
python tools/build.py
```

크롬으로 교재·모의고사 PDF를 만듭니다(정답·해설이 펼쳐진 상태).
