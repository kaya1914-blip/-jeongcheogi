과락이 없다는 것을 이용하라

정보처리기사와 가장 다른 점입니다. 과목별 최저 점수(과락)가 없어, 자신 없는 과목은 통째로 버려도 총점만 채우면 합격합니다.

01합격 셈법 — 30문항

  • 50문항 100점 만점, 60점 = 30문항 정답이면 합격. 20문항은 틀려도 됩니다.
  • 과락이 없으니 한 과목을 0점 맞아도 나머지에서 30개를 채우면 됩니다.
◎버릴 과목 vs 챙길 과목

최근 회차(2024~2025) 분석 결과, 단일 주제로 리눅스 명령어가 압도적 1위입니다. 그다음 TCP/UDP·포트 → DNS/DHCP → 응용 프로토콜 → 네트워크 장비 순. 즉 3과목(리눅스 명령어·권한)과 2과목(포트·프로토콜)에서 암기로 벌면 합격선은 넉넉합니다. 의외로 서브넷 계산은 비중이 크지 않으니 공식만 익혀 두고, 낯선 과목은 개념만 훑어도 됩니다.

02이 시험의 성격

  • 주관: 한국정보통신자격협회(ICQA). 국가공인 민간자격.
  • 기출 재출제 비중이 높습니다 — 개념 + 기출 반복이 정석(정처기와 같음).
  • 암기 승부입니다 — 리눅스 명령어·포트번호·장비 계층을 외우면 절반 이상 확보됩니다. 서브넷 계산은 공식만 익혀 두면 됩니다.

1과목네트워크 일반

통신의 뼈대 개념입니다. 문항 수는 적지만 OSI 7계층은 다른 과목의 기초라 반드시 잡아야 합니다. 개념 위주라 비전공자도 득점하기 좋습니다.

1.1통신 기초 · 전송 방식

전송 방향

방식뜻예
단방향(Simplex)한쪽으로만TV·라디오 방송
반이중(Half Duplex)양방향이나 동시엔 안 됨(번갈아)무전기(워키토키)
전이중(Full Duplex)양방향 동시 가능전화

전송 방식 · 오류/흐름 제어

  • 직렬 전송(한 줄로 차례차례, 원거리·느림·저비용) vs 병렬 전송(여러 줄 동시, 근거리·빠름).
  • 동기식(문자 여럿을 블록으로, 빠름) vs 비동기식(문자마다 시작/정지 비트, 느림).
  • 오류 제어 — 패리티 검사(홀수/짝수), CRC(순환중복검사, 강력), 해밍코드(오류 정정), 체크섬.
  • 흐름 제어 — 정지-대기(Stop-and-Wait), 슬라이딩 윈도우(여러 개를 한꺼번에).

교환 방식

  • 회선 교환(Circuit) — 통화처럼 경로를 미리 독점. 실시간 유리, 효율 낮음.
  • 패킷 교환(Packet) — 데이터를 조각(패킷)으로 쪼개 각자 보냄. 인터넷 방식. 가상회선(순서 보장)과 데이터그램(순서 무보장)으로 나뉨.
☀아침 5분 복습 — 1.1
  • 단방향/반이중(번갈아)/전이중(동시).
  • CRC=오류 검출, 해밍코드=오류 정정.
  • 흐름제어: 정지-대기 / 슬라이딩 윈도우.
  • 회선 교환(독점) vs 패킷 교환(조각·인터넷).
✓기출 유형 체크 — 1.1
Q1무전기처럼 양방향이지만 동시에는 송수신할 수 없는 통신 방식은?
정답 반이중(Half Duplex).
Q2오류를 검출할 뿐 아니라 정정까지 할 수 있는 코드는?
정답 해밍 코드(Hamming Code). 패리티·CRC는 검출만.

1.2OSI 7계층 — 이 시험의 뿌리

OSI 7계층은 통신을 7단계로 나눈 국제표준입니다. 계층 순서 · 각 계층의 역할 · 장비 · PDU · 프로토콜을 묶어서 외우면 여러 과목이 한꺼번에 풀립니다.

계층이름역할 / 장비 · PDU
7응용(Application)사용자 서비스 — HTTP·FTP·SMTP·DNS
6표현(Presentation)암호화·압축·인코딩(형식 변환)
5세션(Session)연결(대화) 설정·유지·종료
4전송(Transport)TCP/UDP·포트 — PDU: 세그먼트
3네트워크(Network)IP·라우터 — PDU: 패킷 · 라우팅
2데이터링크(Data Link)MAC·스위치·브리지 — PDU: 프레임
1물리(Physical)케이블·허브·리피터 — PDU: 비트
암기법 · 7계층(1→7)물 · 데 · 네 · 전 · 세 · 표 · 응 — "물데네전 세표응".
PDU(1→4): 비트 → 프레임 → 패킷 → 세그먼트 ("비프패세").

데이터링크 계층은 MAC 주소로 같은 네트워크 안에서 전달하고, 흐름·오류 제어(LLC)와 매체 접근(MAC) 두 부계층으로 나뉩니다. 네트워크 계층은 IP 주소로 다른 네트워크까지 경로를 정합니다.

☀아침 5분 복습 — 1.2
  • 순서: 물·데·네·전·세·표·응.
  • 장비: 물리=허브/리피터 · 데이터링크=스위치/브리지 · 네트워크=라우터.
  • PDU: 비트→프레임→패킷→세그먼트.
  • 주소: 2계층=MAC / 3계층=IP.
✓기출 유형 체크 — 1.2
Q1OSI 7계층에서 라우터가 동작하며 IP 주소로 경로를 정하는 계층은?
정답 네트워크 계층(3계층).
Q2전송 계층의 데이터 단위(PDU)는?
정답 세그먼트(Segment). 3계층=패킷, 2계층=프레임.
Q3데이터링크 계층에서 사용하는 주소는?
정답 MAC 주소(물리 주소). 48비트.

1.3네트워크 분류 · 토폴로지

규모별 분류

  • LAN(근거리·건물 내, 고속·저오류) · MAN(도시권) · WAN(광역·국가 간, 저속·고오류).
  • PAN(개인·블루투스), SAN(스토리지 전용망), VPN(공용망 위 암호화 가상 전용선).

토폴로지(망 구성)

형태구조 · 특징
성형(Star)중앙 장비에 모두 연결. 관리 쉬움 · 중앙 고장 시 전체 마비
버스형(Bus)한 회선 공유. 저렴 · 회선 끊기면 전체 영향 · 충돌
링형(Ring)고리 모양. 토큰 방식과 짝 · 한 노드 고장이 전파
망형(Mesh)서로 직접 연결. 신뢰성 최고·비용 최고 · 회선 n(n-1)/2
트리형(Tree)계층적 가지치기. 성형의 확장
☀아침 5분 복습 — 1.3
  • LAN(근거리·고속) · WAN(광역·저속).
  • 성형=중앙 죽으면 끝 / 버스형=회선 공유 / 링형=토큰 / 망형=n(n-1)/2.
✓기출 유형 체크 — 1.3
Q1노드 5개를 망형(Mesh)으로 완전 연결할 때 필요한 회선 수는?
정답 10개. n(n-1)/2 = 5×4/2.

1.4매체 접근 제어(MAC)

여러 장비가 한 회선을 나눠 쓸 때 충돌을 막는 규칙입니다. LAN 표준 IEEE 802 시리즈와 함께 나옵니다.

방식동작표준
CSMA/CD회선을 듣고 보냄, 충돌 감지 후 재전송(유선 이더넷)IEEE 802.3
CSMA/CA충돌을 미리 회피(무선은 충돌 감지 불가)IEEE 802.11 (무선랜)
토큰 링토큰(순번표)을 가진 노드만 전송IEEE 802.5
토큰 버스버스형에서 토큰 사용IEEE 802.4
단골 함정 · CD vs CA유선(이더넷)=CD(충돌 감지, Detection), 무선(와이파이)=CA(충돌 회피, Avoidance). 무선은 충돌을 감지할 수 없어 미리 피합니다.

주요 IEEE 802 — 802.1(브리지·VLAN), 802.2(LLC), 802.3(이더넷/CSMA-CD), 802.5(토큰링), 802.11(무선랜), 802.15(블루투스·ZigBee — 저전력·저가·근거리 IoT용).

☀아침 5분 복습 — 1.4
  • 유선=CSMA/CD(802.3), 무선=CSMA/CA(802.11).
  • 802.3 이더넷 · 802.5 토큰링 · 802.11 무선랜 · 802.15 블루투스.
✓기출 유형 체크 — 1.4
Q1무선 LAN(IEEE 802.11)에서 사용하는 매체 접근 제어 방식은?
정답 CSMA/CA(충돌 회피).
Q2IEEE 802.3은 어떤 기술의 표준인가?
정답 이더넷(CSMA/CD).

2과목TCP/IP

이 시험의 중심입니다. 서브넷 계산·IP 클래스·프로토콜·포트번호가 반복 출제됩니다. 특히 서브넷팅만 확실히 잡으면 계산 문제를 통째로 가져갑니다.

2.1TCP/IP 4계층

OSI 7계층을 실무용으로 4개로 합친 것이 TCP/IP 4계층입니다.

TCP/IPOSI 대응프로토콜

전송(Transport)4TCP · UDP
인터넷(Internet)3IP · ICMP · IGMP · ARP · RARP

IPv4는 32비트(8비트씩 4옥텟, 0~255). 첫 옥텟 값으로 클래스가 갈립니다 — 첫 숫자만 보면 판별됩니다.

클래스첫 옥텟기본 서브넷마스크용도
A0~127255.0.0.0 (/8)대형
B128~191255.255.0.0 (/16)중형

E240~255—연구·예약

  • 사설: 10 / 172.16~31 / 192.168.
  • 127.0.0.1=루프백, 255.255.255.255=브로드캐스트.
✓기출 유형 체크 — 2.2

2.3서브넷팅 — 계산의 핵심

서브넷팅은 하나의 네트워크를 여러 개로 쪼개는 것입니다. 계산 공식만 손에 익히면 매 회차 나오는 계산 문제를 확보합니다.

세 가지 공식

구하는 것공식
서브넷당 호스트 수2^(호스트 비트) − 2  (−2 = 네트워크·브로드캐스트)
서브넷 개수2^(빌린 비트)
호스트 비트 수32 − 프리픽스(/n)

자주 쓰는 값 — 통째로 외우기

프리픽스서브넷마스크호스트 수

/25255.255.255.128126
/26255.255.255.19262
/27255.255.255.22430
/28255.255.255.24014

예: 192.168.10.0/26 — 호스트 비트 6개 → 2⁶−2 = 62대, 서브넷은 /24 대비 4개(.0 / .64 / .128 / .192).

암기 팁마스크 뒷자리 값 128·192·224·240·248·252만 외우면 프리픽스↔마스크↔호스트가 다 연결됩니다. 프리픽스가 1 늘 때마다 호스트는 절반.
☀아침 5분 복습 — 2.3
  • 호스트 수 = 2^(32−프리픽스) − 2.
  • 암기: /24=254 · /26=62 · /27=30 · /28=14 · /30=2.
  • 마스크 뒷자리: 128·192·224·240·248·252.
✓기출 유형 체크 — 2.3
Q1서브넷마스크가 /27일 때 서브넷당 사용 가능한 호스트 수는?
정답 30개. 2^(32−27)−2 = 32−2.

정답 /26. 192=11000000 이라 앞 2비트 추가 → 24+2.

4.3스위칭 · VLAN · STP

  • VLAN — 하나의 스위치를 논리적으로 여러 네트워크로 분리. 브로드캐스트 도메인 분할, 보안·성능 향상.
  • 트렁크(Trunk) — 여러 VLAN을 한 회선으로 전달(태그: IEEE 802.1Q).
  • STP(Spanning Tree Protocol) — 스위치 루프(순환)를 막는 프로토콜(IEEE 802.1D).
  • 스위칭 방식 — Store-and-Forward(전체 받고 검사 후 전송·안전) / Cut-through(주소만 보고 즉시·빠름).
☀아침 5분 복습 — 4.3
  • VLAN=논리적 분리(802.1Q 태그) / STP=루프 방지(802.1D).
  • 스위칭: Store-and-Forward(안전) / Cut-through(빠름).
✓기출 유형 체크 — 4.3
Q1스위치 네트워크에서 루프(loop)로 인한 브로드캐스트 폭주를 막는 프로토콜은?
정답 STP(Spanning Tree Protocol).

①UTP 케이블 제작 — 색 순서가 전부

랜선 8가닥의 배열 순서를 외우는 게 핵심입니다. T568B를 기준으로 외우고, T568A는 주황↔초록만 맞바꾼 것으로 기억하면 됩니다.

◎실수 포인트

색을 맞춰도 구리선이 커넥터 끝까지 닿지 않으면 불통입니다. 피복을 조금 길게 벗겨 8가닥을 커넥터 안쪽 끝까지 밀어넣고 압착하세요. 테스터에서 1~8이 순서대로 켜지면 다이렉트, 3·6이 반대편과 교차로 켜지면 크로스입니다.

③서브넷 설계 — 3단계 절차

「호스트 N대가 필요한 서브넷을 설계하라」가 대표 유형입니다. 다음 3단계로 풉니다.

  1. 필요 호스트 수 → 호스트 비트 h: 2h − 2 ≥ N 을 만족하는 가장 작은 h. (예: 50대 필요 → 26−2=62 ≥ 50 → h=6)
  2. 서브넷 마스크: 프리픽스 = 32 − h. (h=6 → /26 → 255.255.255.192)
  3. 대역 나열: 블록 크기 = 256 − 마스크 마지막 옥텟. (/26 → 256−192=64 → .0 / .64 / .128 / .192 네 대역)

각 대역에서 첫 주소 = 네트워크, 마지막 주소 = 브로드캐스트이고 그 사이가 실제 사용 가능한 IP입니다.

④Windows · Linux 설정 단답

  • Windows IP 확인·갱신: ipconfig /all · ipconfig /release · ipconfig /renew
  • Linux IP 설정: ifconfig 또는 ip addr, 경로 route, DNS는 /etc/resolv.conf
  • 연결 점검: ping, 경로 추적 tracert(Win)·traceroute(Linux), 포트·세션 netstat -an
  • 권한·서비스: 권한 chmod 755, 소유자 chown, 서비스 systemctl start / enable
◎마무리

실기는 케이블 색 순서와 Cisco 기본 흐름(enable → conf t → interface → ip address → no shut → copy run start), 이 두 줄기만 손에 익히면 크게 어렵지 않습니다. 나머지는 이미 필기에서 다졌습니다.
